## Проблема

Квест: «Нам нужно внедрять ИИ в работу». Задача — автоматизировать юридический анализ и подготовку коммерческого предложения по регистрации объектов недвижимости (склады, заводы, цеха). Внутри — гигантская стена текста с жёсткой логикой, которую модель должна была держать в контексте.

## Решение

Первый агент на базе GPTs: чистый промпт-инжиниринг. Жёсткие лимиты («Цена < X → Red Flag»), матрица рисков (15 условий проверки обременений), генератор КП — сборка документа по ГОСТу. Юридическую логику перевели на язык алгоритмов. Сейчас архитектуру можно было бы разбить в n8n: Input → Классификатор (AI) → Калькулятор → Генератор КП (AI) → Output — надёжнее и масштабируемее.

## Результат

Агент работает, думающая модель вывозит хаос из условий и выдаёт чистый результат. Живое доказательство: можно не кодить, а думать алгоритмами и создавать цифрового сотрудника, который заменит отдел.

## Стек

OpenAI (GPTs, затем актуальная модель), промпт-инжиниринг, при необходимости — n8n для разбивки этапов.

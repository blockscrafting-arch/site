# Цели Яндекс.Метрики (JavaScript-события)

Счётчик: **108173739** (задаётся в [`src/utils/site.ts`](../src/utils/site.ts)).

В интерфейсе Метрики создайте цели типа **JavaScript-событие** с **точным** идентификатором из таблицы (без символов `/ \ & # ? = "` — [документация](https://yandex.ru/support/metrica/objects/reachgoal.html)).

| Идентификатор цели | Когда срабатывает |
|--------------------|-------------------|
| `form_sent` | Успешная отправка формы на `/contact` (`reachGoal` из React) |
| `cta_contact` | Кнопки «Обсудить задачу», «Написать» и т.п. (компонент `Button` с `dataYmGoal`) |
| `cta_cases` | «Смотреть кейсы», «Все кейсы», «← Кейсы» на странице кейса |
| `cta_guides_list` | «Все инструкции» внизу страницы гайда |
| `nav_contact` | Пункт «Контакты» в меню/футере, юридические страницы, 404 |
| `nav_guides` | «← Инструкции» на гайде, кнопка «Инструкции» на 404 |
| `nav_about` | «Подробнее обо мне» в блоке AboutPreview (если подключён) |
| `nav_services` | «Подробнее обо всех услугах» на главной |
| `telegram_click` | Личный Telegram `@goutach` (кнопки и ссылки с атрибутом) |
| `telegram_channel_click` | Канал `@vladexecute`, карточка «Мой блог» на контактах, CtaChannel |
| `outbound_kwork` | Карточка Kwork на `/contact` |
| `outbound_max` | Карточка МАХ на `/contact` |
| `mailto_click` | Клик по e-mail (`mailto:`) |
| `case_related_click` | Карточка в блоке «Похожие кейсы» |
| `case_product_open` | Карточка продукта в кейсе («Открыть в Telegram» и т.д.) |
| `guide_read` | Прокрутка `/guides/...` примерно до 90% (один раз за сессию на URL) |
| `guide_nav_prev` | «Назад» между инструкциями |
| `guide_nav_next` | «Далее» между инструкциями |
| `guide_related_click` | Карточка в блоке «Ещё инструкции» |
| `scroll_depth_25` | Глубина прокрутки страницы ≥ 25% |
| `scroll_depth_50` | ≥ 50% |
| `scroll_depth_75` | ≥ 75% |
| `scroll_depth_100` | 100% |
| `error404_home` | Кнопка «На главную» на странице 404 |

После создания целей проверьте срабатывание в отчёте «Конверсии» и в режиме отладки счётчика.

Для рассылок, парсинга или мультиаккаунтов нужны аккаунты Telegram в формате, который читают скрипты (session + JSON или TData). Покупать удобно на маркетплейсе с проверенными поставщиками. Важно: прокси оформите по инструкции [Прокси (px6)](/guides/proxy-px6) и используйте только той же страны, что и аккаунт — иначе высокий риск блокировок.

## Где покупать

Маркетплейс [dark.shopping](https://dark.shopping/category/view/telegram), раздел **Telegram**. Подкатегории: «Ручная регистрация», «Авторег», «Telegram Premium», «Каналы/Группы/Чаты» и др. Для автоматизации обычно нужны «Ручная регистрация» или «Авторег» — в описании товара должно быть указано, что выдаётся **session + JSON** и/или **TData**.

## Какие форматы нужны

- **Session + JSON** — универсальный вариант. Файл сессии и JSON с данными подходят для библиотек Telethon, Pyrogram и аналогов. В карточке товара ищите формулировки «SESSION + JSON», «session+json».
- **TData** — папка или архив с данными десктоп-клиента Telegram. Нужен, если в проекте используется работа через TData. В описании: «TDATA», «TData», «TDATA + SESSION + JSON».

Уточните у разработчика, какой формат нужен в вашем проекте (session+json или tdata).

## Прокси той же страны — обязательно

Аккаунт должен использоваться только через прокси из **той же страны**, что и аккаунт. Примеры: аккаунт США (+1) — прокси США; аккаунт Индонезия (+62) — прокси Индонезия. Выход с другого региона часто приводит к ограничениям или блокировке со стороны Telegram.

Порядок действий: сначала выбрать страну под задачу → купить прокси этой страны по инструкции [Прокси (px6)](/guides/proxy-px6) → затем покупать аккаунты с той же страной и в нужном формате.

## Как выбрать товар на маркетплейсе

1. Откройте [категорию Telegram](https://dark.shopping/category/view/telegram), при необходимости отфильтруйте по подкатегории (Ручная регистрация / Авторег).
2. В описании товара проверьте: страна (например +1 США, +62 Индонезия), наличие «TDATA + SESSION + JSON» или «SESSION + JSON».
3. Обратите внимание на гарантию замены, процент брака, отзывы.
4. После оплаты данные (ссылка на скачивание или выдача в личку) приходят по правилам маркетплейса — сохраните файлы сессии/JSON или архив TData.

## Что прислать разработчику

В защищённом виде (личное сообщение):

- файлы сессии и JSON или архив TData (как выдал продавец);
- данные прокси для этого аккаунта: IP:port, логин, пароль, страна — по инструкции [Прокси (px6)](/guides/proxy-px6).

Один аккаунт — один прокси той же страны. Данные используются только для настройки и не передаются третьим лицам.

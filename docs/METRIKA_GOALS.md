# Цели Яндекс.Метрики (JavaScript-события)

Счётчик: **108173739** (задаётся в [`src/utils/site.ts`](../src/utils/site.ts)).

В интерфейсе Метрики создайте цели типа **JavaScript-событие** с **точным** идентификатором из таблицы (без символов `/ \ & # ? = "` — [документация](https://yandex.ru/support/metrica/objects/reachgoal.html)).

| Идентификатор цели | Когда срабатывает |
|--------------------|-------------------|
| `form_sent` | Успешная отправка формы на `/contact` |
| `cta_contact` | Клик по кнопкам «Обсудить задачу», «Написать» и т.п. (атрибут `data-ym-goal`) |
| `cta_cases` | Клик «Смотреть кейсы», «Все кейсы» |
| `cta_guides_list` | Клик «Все инструкции» на странице гайда |
| `telegram_click` | Личный Telegram (`t.me/goutach` и аналогичные ссылки с атрибутом) |
| `telegram_channel_click` | Клик по кнопке канала `@vladexecute` |
| `guide_read` | Прокрутка страницы инструкции `/guides/...` примерно до 90% (один раз за сессию на URL) |
| `guide_nav_prev` | Клик «Назад» в навигации между инструкциями |
| `guide_nav_next` | Клик «Далее» в навигации между инструкциями |
| `guide_related_click` | Клик по карточке в блоке «Ещё инструкции» |
| `case_related_click` | Клик по карточке в блоке «Похожие кейсы» |
| `scroll_depth_25` | Глубина прокрутки страницы ≥ 25% |
| `scroll_depth_50` | ≥ 50% |
| `scroll_depth_75` | ≥ 75% |
| `scroll_depth_100` | 100% |

После создания целей проверьте срабатывание в отчёте «Конверсии» и в режиме отладки счётчика.
